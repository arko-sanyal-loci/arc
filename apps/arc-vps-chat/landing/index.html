What LOCI is

Persistent, inspectable memory—not a bigger prompt.

LOCI (Layered Output and Context Intelligence) is an evolving architecture and codebase for organizing an agent's memory outside its immediate context window. It combines versioned facts, time- and relevance-aware retrieval, local persistence, and analytical feedback so an agent can recall what matters without treating every past message as equally useful.

Layered recall

Heat and retrieval tiers help prioritize relevant, current information while keeping historical records available for review.

Traceable change

Versioned facts and Glassbox review records make changes and routing decisions easier to inspect.

Quality-first work

Routing favors the model and process that can meet the task's quality bar; resource savings are secondary.

Recovery in mind

Local persistence, integrity checks, and encrypted backup workflows support deliberate recovery instead of silent fallback.

Current boundaries: LOCI and the Billo platform snapshot are not yet one integrated production runtime. Authenticated cross-runtime memory replication is not enabled. Hash-chain verification can reveal changes, but by itself cannot prevent a privileged host administrator from rewriting data and its verifier; stronger tamper evidence needs an independently controlled witness.
