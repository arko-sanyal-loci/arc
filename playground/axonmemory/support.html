Where Arc lives now

Evolution Vapes is the vape retail business website. Axon Memory is the public documentation and recovery guide. Arc has a workstation-local interface and a separate VPS continuity service. Treat them as distinct endpoints with distinct roles.

Endpoints agents should use

Workstation-local Arc

http://127.0.0.1:7860

Loopback interface and memory API. Reachable only by software on the workstation itself. Health check: /api/health. Do not substitute an Evolution Vapes or Axon Memory public URL for this address.

Workstation media monitor

http://127.0.0.1:11500

Local telemetry and consent-gated capture UI at /capture. Browser access requires explicit camera/microphone permission and Start. Device presence alone does not mean capture is active.

Remote continuity chat

https://billo.tech/arko/chat

Protected Arc chat hosted on the VPS. Use when the workstation is offline; sign-in is required. Do not place credentials or recovery codes in public notes or chat.

Public documentation

https://axonmemory.com/

Public project overview, paper links, repository map, support notes and recovery guidance. It is not the private memory database or backup archive.

Domain and network clarification

  • 127.0.0.1 is a loopback address: it refers to the same device that makes the request. It is not an internet-facing server address and is not an IP address customers need allowlisted.
  • Public visitors reach Axon Memory and Billo Tech by their HTTPS domains. Customers reach Evolution Vapes through its public domain and the site's public DNS/hosting configuration.
  • Hostinger IP Manager allow/block rules apply to source IP addresses connecting to a website. Do not add 127.0.0.1 as a customer allowlist entry or block rule. Ordinary customers need no IP allowlisting to browse a public site.
  • Axon Memory is a separate addon website on the same shared hosting plan, with its own document root. It was not attached as an alias to Evolution Vapes.

Local endpoints are intentionally loopback-only. Never expose ports 7860 or 11500 publicly or add broad firewall rules to make loopback reachable from the internet. For remote access, use the authenticated VPS chat.

Current verification limits

The workstation Arc health API and both local GPU lanes have responded in prior smoke checks. The camera node is detected and a one-frame local capture succeeded. Actual browser audio/video capture and journal synchronization still require an explicitly started, consented browser session. The VPS chat is separate and remains available when the workstation is offline.

This page contains endpoint guidance only. It publishes no credentials, private memory, evidence clips, or backup files. Check live service telemetry before assuming a worker or media stream is healthy.
