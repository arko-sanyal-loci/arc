THE WORKSPACE

One loop, four experiments.

Each part asks a specific question. The aim is to make the whole system easier to inspect and improve.

01LOCAL PROTOTYPE

LOCI

Contextual memory

Organises source-linked information by relevance and recency, so an answer can return to the evidence it came from.

Explore research ↗
02LOCAL PROTOTYPE

ARC

Adaptive runtime

Tests complexity-aware model routing across a local NVIDIA RTX lane and an Intel Arc lane, with fallback and load reporting.

Explore runtime ↗
03DESIGN + CODE

Glassbox

Provenance and review

Develops an inspectable record for source references, revisions and decisions. Deployed ledger status is not claimed here.

Explore the design ↗
04PLAYGROUND

SympRev

Audio and video signals

Experiments with compact descriptions of motion, colour, rhythm and sound. Semantic and emotional readings remain hypotheses.

Explore experiments ↗
